# Sehat Duty Pakistan

A responsive prototype for finding government doctors currently on duty across Pakistan.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Current scope

- Search by doctor, specialty, hospital, and city
- Filter for doctors currently on duty
- Doctor duty-detail modal with official hospital contact
- City shortcuts and responsive mobile navigation
- Sample verification timestamps and public-service guidance

All listings are dummy data for demonstration. A later phase can connect the directory to Supabase, add hospital administration, CSV imports, and location-based search.
